連結 Google Sheets
依步驟設定後，即可將記帳資料同步到你的 Google 試算表。
  1. 開啟 sheets.new 建立新試算表
  2. 點選「延伸功能」→「Apps Script」，貼上以下程式碼後儲存
function doPost(e) { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); const data = JSON.parse(e.postData.contents); if (data.action === 'sync') { sheet.clearContents(); sheet.appendRow(['日期','類別','項目','金額','備註']); data.entries.forEach(r => { sheet.appendRow([r.date, r.cat, r.name, r.amt, r.note||'']); }); return ContentService.createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } }
  1. 點「部署」→「新增部署」→ 類型選「網頁應用程式」→ 存取權選「所有人」→ 部署
  2. 複製「網頁應用程式網址」貼到下方
